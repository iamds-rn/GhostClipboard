**GhostClipboard** is a security-first, developer-grade native macOS clipboard manager built in Swift 5.9 (`AppKit` + `SwiftUI` + `SQLite3` + `CryptoKit`). Unlike traditional clipboard managers that silently log your passwords, API tokens, and private keys in plaintext databases, GhostClipboard evaluates every pasteboard event **before persistence**—blocking secrets on arrival and encrypting normal history with `AES-256-GCM` and a zero-plaintext `HMAC-SHA256` blind search index.

---

## Why GhostClipboard?

Most clipboard managers treat every `⌘C` identically, turning your local disk into a high-value target containing AWS keys, `.env` secrets, JWTs, and password manager copies.

GhostClipboard implements a strict **7-stage zero-trust clipboard lifecycle**:

```text
COPY ──► DETECT ──► CLASSIFY ──► PROTECT ──► RETRIEVE ──► PASTE ──► EXPIRE
```

Every clipboard event is classified into one of **4 Sensitivity Levels (`0`–`3`)** before any disk write can occur:

| Level | Tier | Disposition | Examples |
| :--- | :--- | :--- | :--- |
| **Level 0** | `normal` | **Encrypted Persistence** (`persistStandard` — `AES-256-GCM` + `HMAC-SHA256` blind FTS5 index) | Code snippets, URLs, JSON, SQL, shell commands, prose |
| **Level 1** | `potentiallySensitive` | **10-Minute Memory Quarantine** (`memoryOnlyEphemeral` — auto-expiring, never written to disk by default) | High-entropy opaque tokens or password candidates without a known vendor prefix |
| **Level 2** | `sensitive` | **Immediate Discard** (`discardImmediately` — blocked before storage; only an anonymous event counter is incremented) | 1Password/Bitwarden/Keychain copies, PEM keys, AWS/GitHub/OpenAI/Anthropic/Stripe/Slack/Google tokens, JWTs, DB URLs, `.env` secrets |
| **Level 3** | `ephemeralSecret` | **RAM-Only Countdown** (`memoryOnlyEphemeral` — optional 30s ephemeral OTPs & transient copies, purged from RAM & system pasteboard on expiry) | One-time verification codes (OTPs), transient pasteboard copies |

## Architecture & Security Model

### 1. Pre-Persistence `SensitiveContentEngine`
Before any SQLite transaction is opened, `SensitiveContentEngine` inspects both `NSPasteboard` metadata and payload patterns:
- **Pasteboard Metadata & App Exclusions**: Automatically honors `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, and password manager markers (`com.agilebits.onepassword`, `com.bitwarden.desktop`, `com.apple.keychainaccess`, Dashlane, KeePassXC, Proton Pass, Enpass).
- **Cryptographic & Cloud Secret Signatures**: Detects and discards PEM/OpenSSH private keys (`RSA`, `EC`, `OPENSSH`, `PGP`), AWS Access Keys (`AKIA...` / `ASIA...`), GitHub PATs (`ghp_`, `github_pat_`, `gho_`, `ghs_`, `ghu_`), OpenAI (`sk-...`, `sk-proj-...`), Anthropic (`sk-ant-...`), Stripe (`sk_live_...`, `rk_live_...`), Slack (`xoxb-`, `xoxp-`), Google API keys (`AIza...`), JSON Web Tokens (`eyJ...`), database connection strings (`postgres://`, `mysql://`, `mongodb+srv://`, `redis://` with embedded credentials), and `.env` secret assignments.
- **Shannon Entropy Heuristics**: Identifies high-entropy standalone password/token candidates (`≥ 3.7 bits/char` across 4 character classes or `≥ 4.25 bits/char` across 3+ classes) and quarantines them in memory for 10 minutes while avoiding false positives on normal source code, UUIDs, hex hashes, URLs, file paths, and prose.
- **Optional 30s Ephemeral OTPs**: Conservatively detects 6–8 digit 2FA/OTP codes and holds them in RAM (`Level 3 — ephemeralSecret`) before scrubbing them from memory and `NSPasteboard.general`.

### 2. `AES-256-GCM` Vault + Zero-Plaintext `HMAC-SHA256` Blind Indexing
- **Payload Encryption**: Every persisted clip payload is encrypted using `CryptoKit.AES.GCM` with a unique 96-bit nonce and 128-bit authentication tag (`AES-256-GCM`).
- **Master Key Protection**: A 256-bit symmetric master key is generated via `SymmetricKey(size: .bits256)` and stored in the macOS Keychain (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`) with a `0600` local vault key fallback.
- **Zero-Plaintext Blind Search Index (`clips_fts`)**: To provide sub-5ms full-text search without leaking plaintext words into SQLite's `clips_fts` table, GhostClipboard derives a dedicated 256-bit subkey via `HKDF<SHA256>` (`info: "GhostClipboard-BlindIndex-HMAC-v1"`). Words, camelCase subwords, and prefixes (3–24 chars) are hashed into deterministic `bi_<16-hex>` HMAC tokens (`HMAC<SHA256>`). **`clips_fts` stores zero plaintext tokens on disk.**

### 3. Background Efficiency & Low Footprint
- **~10.7 MB Resident Memory (RSS)**: Engineered with lightweight value types, SQLite WAL mode (`PRAGMA synchronous=NORMAL`), and zero heavy Electron/WebView runtime overhead.
- **`0 Hz` Idle Ephemeral Timer**: The ephemeral countdown timer runs **only** while an active RAM-only secret/OTP is present (`ephemeralClips` non-empty) and cancels itself immediately when the queue drains or monitoring is paused.
- **Kernel-Coalesced Polling**: Uses a `DispatchSourceTimer` with `150ms` leeway and `NSPasteboard.general.changeCount` O(1) integer checks, waking only when the system clipboard actually mutates.
- **Pre-Compiled `RegexCache` & Pressure-Evicted `NSCache`**: All classification and security regular expressions are compiled once at startup. Decrypted previews are cached in a bounded `NSCache` (`countLimit = 96`, `totalCostLimit = 2 MB`) that automatically purges on macOS memory pressure or application backgrounding.

## Features & Developer Actions

### Intelligent Categorization & Code Detection
- **9 Automatic Categories (`ClipCategory`)**: `Code` (`code`), `Colors` (`hex_color`), `Links` (`url`), `OTP` (`otp`), `Credentials` (`credential`), `Markdown` (`markdown`), `JSON` (`json`), `Terminal` (`terminal_command`), and `Plain Text` (`plain_text`).
- **17-Language Heuristic Code Detection (`ProgrammingLanguage`)**: Automatically identifies `Swift`, `Python`, `JavaScript`, `TypeScript`, `Rust`, `Go`, `Java`, `C`, `C++`, `Kotlin`, `Ruby`, `PHP`, `SQL`, `HTML`, `CSS`, `Shell`, and `PowerShell`.

### Native macOS Surfaces
- **Floating Quick Palette (`⌥Space` or Custom Global Shortcut)**: Spotlight-style `NSPanel` overlay with instant blind-index search, category filter pills, live syntax/metadata preview, and keyboard-first navigation (`↑`/`↓`, `↩`, `⌘1`–`⌘9`).
- **Direct Paste (`⌘V` Synthesis)**: Optional one-step paste directly into the previously active window via macOS Accessibility (`CGEvent`), with automatic fallback to clipboard copy.
- **3-Pane Main Workspace**: Full history browser with category/source-app filtering, pinned items, live SQLite & memory telemetry, and an interactive **Live Detector Sandbox** to test how `SensitiveContentEngine` classifies any string.
- **Security & Retention Center**: Granular toggles for password/API-key/OTP handling, app exclusion bundle IDs, auto-expiry windows, and one-click secure wipe (`DELETE` + `VACUUM`).

### Built-In Developer Actions (`DeveloperActionsEngine`)
Transform clips on the fly before pasting or saving as a new clip:
- **JSON Toolkit**: Pretty-print (`2 spaces`), Minify, Sort Keys Alphabetically, and Escape/Unescape string literals.
- **JWT Inspector**: Offline decode of JSON Web Token `alg`/`typ` headers, payload claims, and human-readable `exp`/`iat`/`nbf` timestamps.
- **`cURL` Code Generator**: Convert `curl` commands (methods, `-H` headers, `-d`/`--data-raw` bodies, `-u` Basic Auth, `-G` query params) directly into **`JavaScript fetch()`** or **`Swift URLRequest`** snippets.
- **Timestamp Converter**: Instant bi-directional conversion between Unix Epoch seconds, Unix milliseconds, ISO-8601 (`UTC` & local), RFC-2822, and SQL `TIMESTAMP`.
- **Color Converter**: Parse and convert between `#HEX`, `rgb()`, `hsl()`, SwiftUI `Color(red:green:blue:)`, and CSS variables with WCAG relative luminance & contrast metrics.
- **Markdown & Text Utilities**: Convert bullet lists to `- [ ]` task checkboxes, wrap snippets in language-tagged Markdown code fences, strip ANSI escape sequences, convert cases (`camelCase`, `snake_case`, `kebab-case`, `SCREAMING_SNAKE_CASE`), Base64 / URL encode & decode, SHA-256 digest, and UUID v4 generation.
- **Sequential Paste Stack (FIFO / LIFO)**: Queue multiple clips and pop them one by one on each paste.

## Build, Bundle & Run Instructions

### Prerequisites
- **macOS 13.0 (Ventura)** or later
- **Swift 5.9+** (Xcode 15+ or Command Line Tools)

### 1. Build Release Binaries
```bash
swift build -c release
```
This compiles both the native GUI executable (`.build/release/GhostClipboard`) and the standalone CLI executable (`.build/release/ghostclipboard-cli`).

### 2. Package & Sign `GhostClipboard.app`
```bash
./scripts/bundle_app.sh
```
This script:
1. Generates `Resources/AppIcon.icns` (if not already present).
2. Builds the universal/release binaries (`GhostClipboard` and `ghostclipboard-cli`).
3. Assembles `dist/GhostClipboard.app` with `Info.plist`, `AppIcon.icns`, and embedded CLI binaries.
4. Signs the bundle and CLI binaries with `Resources/GhostClipboard.entitlements` (using your `Developer ID Application` / `Apple Development` certificate if present, or ad-hoc signing automatically).

To launch the bundled app:
```bash
open dist/GhostClipboard.app
```

### 3. Run the 247-Assertion Verification Suite
GhostClipboard includes a comprehensive, self-contained verification runner covering secret detection, `AES-256-GCM` tamper resistance, zero-plaintext `HMAC-SHA256` blind FTS5 indexing, punctuation/camelCase queries, developer actions, and CLI gating:
```bash
swift run GhostClipboardTests
```

## CLI Usage (`ghostclipboard`)

GhostClipboard ships with a local-only CLI (`./dist/ghostclipboard` or `.build/release/ghostclipboard-cli`) for terminal workflows, scripts, and pipeline integration. By default, CLI read access to clipboard history is gated behind an opt-in preference.

```bash
# 1. Inspect vault status, encryption mode, blocked secret count, and RSS memory
./dist/ghostclipboard status

# 2. Enable local CLI read access
./dist/ghostclipboard enable-cli

# 3. View the 10 most recent clips
./dist/ghostclipboard recent --limit 10

# 4. Search encrypted history via HMAC-SHA256 blind index and output JSON
./dist/ghostclipboard search "query" --json

# 5. List clips filtered by category (code, url, hex_color/color, markdown/md, json, terminal_command/shell, plain_text/text)
./dist/ghostclipboard list --category code

# 6. Revoke CLI read access at any time
./dist/ghostclipboard disable-cli
```
